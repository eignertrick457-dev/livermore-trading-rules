# livermore-trading-rules

> 把《股票大作手回忆录》（杰西·利弗莫尔）的交易思想蒸馏成 AI Agent Skill——一套面向**日内短线期货交易者**的可执行规则清单。

## 这是什么

`SKILL.md` 将利弗莫尔的核心交易思想（最小阻力线、关键点确认、试仓加码、截断亏损让利润奔跑、空仓等待、拒绝消息与情绪化交易）提炼为 8 个模块的中文清单：

| 模块 | 内容 |
|------|------|
| 核心原则 | 9 条底层原则（顺势、时机、试仓验证、情绪反转用法等） |
| 进场判断清单 | 7 项进场门控，逐条过检、一票否决 |
| 加仓规则 | 金字塔式加码的 6 条纪律 |
| 止损规则 | 逻辑位 + 金额位双约束、当日熔断等 6 条 |
| 持仓规则 | 出场只认 3 个信号 |
| 空仓与等待 | 没行情时的 5 条行为准则 |
| 反模式 | 这本书最反对的 10 种做法（一票否决） |
| 适用边界 | 哪些原则已映射到日内、哪些需调整、哪些不适用 |

所有内容为思想提炼与日内场景再映射，不含原文摘录；既可接入 AI Agent 在盘中决策时对照检查，也可直接当人工交易纪律速查卡使用。

## 安装使用

**方式一：作为 Agent Skill 安装**

```bash
git clone https://github.com/eignertrick457-dev/livermore-trading-rules.git
# 将 livermore-trading-rules/ 整个文件夹复制到你的 Agent 技能目录
# （兼容 Anthropic Agent Skills 规范的 skills/ 目录，如 Claude Code、TeleAgent 等）
```

重启 Agent 或刷新技能列表后，当对话涉及"要不要进场 / 要不要加仓 / 止损设在哪 / 单子该不该拿 / 今天做不做"时自动触发。

**方式二：作为系统提示词**

直接将 `SKILL.md` 正文（YAML frontmatter 之后的部分）粘贴到 Agent 的系统提示词或自定义指令中。

**方式三：人工使用**

把 `SKILL.md` 存为速查卡：盘前过一遍"进场判断清单"，盘中对照"反模式"逐条自查。
